# پرونده میدانی (Field Log) — APK Build Instructions

## مراحل ساخت APK (4 قدم ساده)

### 1️⃣ میزبانی (Hosting)
فایل‌های این پوشه را به صورت آنلاین قرار دهید:
- **Netlify**: برو به `app.netlify.com/drop` و فایل‌های این پوشه را کشو و رها کن
- **GitHub Pages**: آپ‌لود کن به مخزن و فعال‌کن Pages
- **Firebase Hosting**, **Vercel**, یا هر CDN دیگری

### 2️⃣ لینک خود را کپی کنید
بعد از آپ‌لود، لینکی شبیه این دریافت خواهی کرد:
```
https://your-site.netlify.app
```

### 3️⃣ APK بساز
برو به **[pwabuilder.com](https://pwabuilder.com)**
- پیست کن URL ات در کادر جستجو
- "Start" کلیک کن
- منتظر اسکن نتیجه → "Android" → "Generate Package" را انتخاب کن
- فایل `.apk` یا `.aab` را دانلود کن

### 4️⃣ نصب کن
**روش الف (ساده ترین):**
- فایل APK را به تلفن منتقل کن
- فایل را باز کن
- "نصب از منابع نامعلوم" را تأیید کن

**روش ب (Play Store):**
- از فایل `.aab` برای آپ‌لود به Google Play Console استفاده کن

---

## فایل‌های موجود

- `index.html` — اپلیکیشن (فارسی، طراحی پریمیوم)
- `manifest.json` — پیکربندی PWA
- `service-worker.js` — پشتیبانی آفلاین
- `icons/` — آیکن‌های اپ (192×192 و 512×512)
